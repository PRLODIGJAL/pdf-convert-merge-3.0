============================================================================
  PDF 转换拼接工具 3.0 · 使用说明书
============================================================================

适用：PDF转换拼接3.0_Mac版 ／ PDF转换拼接3.0_Windows版
      （操作完全一样，只有「能转哪些格式」不同）

一句话：把一批 Word / Excel（Windows 还有 CAD、标签）批量转成 PDF；
也能给一批 PDF 一键换掉首页 —— 把签好字的那份扫描件贴回去。


----------------------------------------------------------------------------
一、两个模式：窗口顶部两个大按钮，点一下切换
----------------------------------------------------------------------------

【导出 PDF】      一批 Office 文件批量转 PDF，打印签字之前那一步。
                  每份原件 → 各自一份 PDF，落在原件所在文件夹里。
                  原件不被动：只写产物，不移动、不改名、不改内容。

【PDF 首页替换】  一份扫好的多页签字页 PDF（一页对应一份原件），把第
                  N 页贴到第 N 份原件的第 1 页，后面几页原样保留。
                  签字页一次扫成册，靠顺序一一对应，不用改名。


----------------------------------------------------------------------------
二、怎么启动
----------------------------------------------------------------------------

Windows  双击「启动PDF转换拼接.bat」；第一次先双击「运行前的环境准备.bat」，
         它会告诉你 Python 环境齐不齐、这台机器能转哪几种格式（把一份文件
         拖到它上面还能「试运行」单独一份，不产生结果）。
Mac      双击「启动PDF转换拼接.command」，首次自动准备环境（等一两分钟）。

Mac 第一次转 Word / Excel 会问授权，点「允许」—— 授权按应用记，允许一次
以后不再问。


----------------------------------------------------------------------------
三、模式一：导出 PDF（4 步）
----------------------------------------------------------------------------

1）顶部点「导出 PDF」
2）点「＋ 添加文件…」挑文件：可一次多选，也可从访达 / 资源管理器拖进窗口。
   散在几个文件夹里就分几次加，重复的自动去重。
3）看一眼「产物名」：默认 = 原件名 + 后缀 + .pdf。后缀可以不填（原件是
   .xlsx / .docx 不会撞名）；填了会记住。
4）点「开始转换」，看表格里的状态和「产物页数」。

页数怎么定：Word 按它自己的分页；Excel 每个工作表一页；图纸 / 标签按它
自己排的页。转完看「产物页数」——读得出来就说明 PDF 真生成了。
撞名时问你一句：是 ＝ 覆盖 ／ 否 ＝ 加编号另存 ／ 取消 ＝ 先别跑。


----------------------------------------------------------------------------
四、模式二：PDF 首页替换（6 步）
----------------------------------------------------------------------------

1）顶部点「PDF 首页替换」
2）「＋ 添加文件…」把要换首页的原件 PDF 加进来
3）先点「预览（先列队，再配对）」
   还没选扫描件时它只做一件事：把原件按文件名排队。屏幕上第 1 行 = 扫描
   件第 1 页，照这个顺序去扫就不会错。
4）把签字页一次扫成一份多页 PDF，填到「扫描件 PDF」那一格
5）再点「预览」→ 自动配成「第 N 行用第 N 页」。份数对不上会整批不执行
   （不会错位硬贴）
6）点「开始替换」

输出文件名必须带后缀（产物也是 .pdf，空着会盖掉原件，工具直接拦住）：
      WI-1032.pdf  +  _已签字   →   WI-1032_已签字.pdf

三组按钮（鼠标停在按钮上会弹出更详细的说明）：
  ① 页序   [页序：正序 / 倒序] 点一下整批切换（扫描仪倒着出纸时用）
  ② 页码   [↑ 与上行对调] / [↓ 与下行对调] 只换用的扫描页，行顺序不变；
           双击某一行 = 直接指定这一行用扫描件的第几页
  ③ 方向   [全部左/右转 90°] 整批转；[横向左/右转 90°] 只转横向页；
           [方向复位] 回默认规则
  ⚠️ 页序和方向是「整批重算」，会把手动调过的个别行清回默认 ——
     先定页序和方向，最后再调个别行。


----------------------------------------------------------------------------
五、支持哪些格式（两版的差别就在这里）
----------------------------------------------------------------------------

  格式             Mac 版                   Windows 版
  --------------------------------------------------------------------
  Word             .doc .docx .docm .rtf    同左
  Excel            .xls .xlsx .xlsm         同左
  CAD              ——（不支持）             .dwg .dxf .dwt .dws
  BarTender 标签   ——（不支持）             .btw（GRA 那类标签模板）

· Word / Excel 用本机 Office 转，保真度最高；没装时退回 LibreOffice。
· CAD 用本机装的 CAD 出图（只把出图设备换成 PDF 打印机，其余照图纸里存的）。
· 一份 .btw 出两个文件：一张标签图片（JPG）+ 一份标签 PDF。
· BarTender 只在 Windows 上、本机装了且接口可用时才认；认不到会在这份的
  「说明」列里指名，不会静默漏掉。「已跳过」= 扩展名不支持或本机没引擎。

⚠️ 标签（GRA 那类）转出来的 PDF 是「图」不是文字：BarTender 把标签渲染
   成图像再导出，所以无法选中、复制、搜索，也认不出字体。这不是转换失败，
   是源文件本身就按图像输出。要文字可读的 PDF，请从源头的 Word / Excel 转。


----------------------------------------------------------------------------
六、常见问题
----------------------------------------------------------------------------

Q：界面说没检测到 Office / CAD / BarTender？
A：软件是在工具打开之后才装的话，它不会自己发现 —— 点「重新检测引擎」。
   Windows 再不行就跑一遍「运行前的环境准备.bat」看它报什么。

Q：一转就失败 / 卡住 / 全是红字？
A：Mac 上第一次会弹系统授权（自动化 / 文件访问），点「允许」—— 一批文
   件只拉起一次 Office，后面不再反复问；授权没给会一直失败，关掉工具重
   开再试。Windows 全是红字就先跑一遍「运行前的环境准备.bat」看它报什么。

Q：首页替换后份数报错？
A：扫描件页数必须等于原件数量。先用「预览」排队，再照这个顺序扫。

Q：双击启动，窗口闪一下就没了 / 说找不到 python3？
A：没装 Python 3。Windows 装时勾「Add python.exe to PATH」；Mac 去
   python.org 下 3.9 以上装上再双击。启动窗口会写出原因，不会静默退出。
